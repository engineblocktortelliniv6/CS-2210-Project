In order to run this program, you must first make sure to have the java SDK installed. 
If you do not, you can find it here: https://www.oracle.com/java/technologies/downloads/

You must open the src folder inside of your terminal.
Next, you must run the command "javac Main.java" followed by "java Main".
The program will then open inside of your terminal!
Make sure to follow the user guide to sign in and understand what the initial values are.
